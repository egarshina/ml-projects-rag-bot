# ML Projects RAG Assistant

RAG-ассистент, отвечающий на вопросы о моих ML-проектах, навыках и контактах.

## Описание
Веб-интерфейс на базе Streamlit, который позволяет задавать вопросы о портфолио. Для ответов используется Retrieval-Augmented Generation: сначала с помощью эмбеддингов SentenceTransformer и векторного индекса FAISS находятся похожие документы, затем фрагменты передаются в GigaChat, который генерирует ответ на основе контекста.

## Структура репозитория
- `app.py` — основное приложение: загрузка документов, создание индекса, подключение к GigaChat, интерфейс Streamlit с ограничением частоты запросов.
- `requirements.txt` — зависимости.
- `README.md` — описание проекта.
- 'REAFME_ENG.md' — описание проекта на английском, так как остальные файлы на английском. Для стабильности и справедливости.

## Используемые технологии
- Python 3
- SentenceTransformers
- FAISS
- Streamlit
- GigaChat API

## Как запустить
1. Клонировать репозиторий.
2. Установить зависимости: `pip install -r requirements.txt`.
3. Задать переменную окружения `GIGACHAT_CREDENTIALS`.
4. Запустить: `streamlit run app.py`.

Или развернуть на Streamlit Cloud, добавив секрет `GIGACHAT_CREDENTIALS` в настройках приложения.

## Результаты
- Бот перечисляет все проекты из портфолио. (Оно указывается пока что в самом app.py; потом хочу сделать доработку, чтобы он автоматически читал все (даже новые) readme файлы из профиля)
- Отвечает о навыках, опыте и контактах.
- Встроено ограничение частоты запросов (rate limiting).
- Показывает источники, на основе которых сгенерирован ответ. (Пока что это краткие описания в файле app.py; после коммита с автоматическим чтением readme будет отсылаться на них)

## Выводы
Проект демонстрирует практическое применение RAG: объединение векторного поиска и генеративной модели для создания ассистента по собственному портфолио. Добавление новых проектов не требует переобучения модели — достаточно обновить список документов.
